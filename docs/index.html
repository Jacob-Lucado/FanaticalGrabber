Send to Steam Value Checker New

Want your new games in your library tracker? One click sends the titles (never the keys) to the Steam Value Checker Discord bot, along with what you paid. Run /library grabber in Discord once to get a link code, paste it into the panel, and that's the whole setup.

Batch Redeem New panel

Once you're on Steam, you'll spot a softly pulsing Batch Redeem bar. Open it, paste your keys (or drop in a .txt file, or pull in the ones you revealed on Fanatical), and it redeems them all on whichever Steam account you're logged into. If you're on the Activate a Product page, the panel just sits right under Steam's own form.

  • Paste your keys even if they're tangled up with other text, or open a .txt file. It picks out anything in Steam's XXXXX-XXXXX-XXXXX format and ignores the rest.
  • Pull in every unredeemed key from your Fanatical orders in one click, and skip the games you already own if you'd like.
  • Remembers which keys were redeemed, already owned or already used, so it won't waste time on them again.
  • Pauses 3 seconds between keys so Steam stays happy, shows you progress as it goes, and has a Stop button if you change your mind.
  • Quietly stops if you get logged out or Steam tells it to slow down.
  • Hands you a CSV report at the end, with what happened to every single key.
  • Don't like where it sits? Drag the bar or the header wherever you want. It remembers.

A heads up: this uses the same redeem request Steam's own site does, which isn't an official API, so it could break if Steam changes things. Try a couple of keys first to be safe. Your keys only ever travel to Steam, and nowhere else.

A few extras while you shop on Steam New

  • Price card on game pages: shows the best price right now, the all-time low, and whether it's already in your library or on your wishlist. It shows prices in your own currency, and needs your Steam Value Checker link code.
  • Bundle check: on a bundle page, see how the bundle stacks up against buying the games one by one.
  • Cart check: nudges you before checkout if something in your cart is cheaper elsewhere, or if you already own it.
  • Key vault: keys you reveal are remembered in your browser only, so you can always see which ones are still waiting to be redeemed.

Install

The easy way: grab it from the Chrome Web Store. It keeps itself up to date, so you never have to think about it again.

Add to Chrome

Brave, Opera and Vivaldi can install from the Chrome Web Store too. Edge will ask you to allow extensions from other stores first.

Prefer the .zip? No problem

The .zip is always the newest version. The Web Store copy waits on a review each time, so the .zip can be a step ahead. You'll install it as an unpacked extension, and it only takes about a minute.

Download .zip (Latest)

  1. Unzip it somewhere you'll remember (don't delete the folder afterwards). Inside you should see manifest.json, content.js, steam.js, background.js, bridge.js and xlsx.full.min.js.
  2. Open your extensions page by going to chrome://extensions, edge://extensions, brave://extensions, opera://extensions or vivaldi://extensions.
  3. Switch on Developer mode. It's in the top right, or in the sidebar on Edge.
  4. Click Load unpacked and choose the folder that has manifest.json in it.
  5. Head to your Fanatical orders and click the orange 🎮 FanaticalGrabber bar in the bottom right. That's it, you're in.

Web Store installs update on their own. If you went the .zip route, swap in the new files, hit Reload on the extension card, and give Fanatical a hard refresh with Ctrl + Shift + R.

Questions people ask

Does it send my keys anywhere?

Nope. Revealing, exporting and copying all happen right in your browser. Keys only go to Steam, and only when you press Redeem. The optional "Send to Steam Value Checker" button shares game titles, never keys. If you want the full story, it's in the privacy policy.

Where do I find the Steam panel?

Open any page on store.steampowered.com and look in the bottom right for the pulsing 🎮 Batch Redeem bar. Click it and the panel opens. On the Activate a Product page it's already open under the form. Just double check you're logged into the Steam account you want the games on.

Can I move the panels?

Yep. Drag the bar or the header, on Fanatical or on Steam, and drop it wherever suits you. Each one remembers its own spot, and when you minimise it, it hops back to its usual corner.

Does Redeem work for keys from other stores?

Not for redeeming. Batch Redeem only handles Steam keys and skips anything that isn't in Steam's format. Exports still include every key, though.

Why did Redeem say I'm not logged in?

Log into store.steampowered.com in the same browser profile, then give it another go. Being signed into the Steam desktop app doesn't count, sadly.

What if Steam rate-limits me?

It stops straight away so you don't dig the hole deeper. Give it about an hour, then try again with smaller batches.

Does it work in Firefox or Safari?

Not right now, sorry. It's built on Chromium's extension system, so it needs a Chromium-based browser.

Something broke. Where do I report it?

Sorry about that! Send me a message on X with your browser, the version number in the panel footer, and whatever message or CSV report it gave you. Ideas for new features are always welcome too.
