What it does

Everything lives in a small panel in the corner of your Fanatical page, and the same bar follows you to Steam.

Reveal All

Clicks every "Reveal Key" button for you, spaced out so the site isn't flooded with requests.

Export in seven ways

Send to Steam Value Checker New

One click sends your game titles (never your keys) to your library in the Steam Value Checker Discord bot, with what you paid for the order. Get a link code once with /library grabber in Discord, paste it in the panel, and you're set.

Batch Redeem New panel

On any Steam store page the extension shows a pulsing Batch Redeem bar. Open it to paste keys, drop in a .txt file or load the keys you revealed on Fanatical, then redeem them all on the Steam account you're logged into. On the Activate a Product page the panel sits right under Steam's own form.

  • Paste keys mixed with other text, or open a .txt file. Only Steam's XXXXX-XXXXX-XXXXX format is used.
  • Load every unredeemed key from your Fanatical orders in one click, and optionally skip games you already own.
  • Remembers keys that were redeemed, owned or already used, and skips them next time.
  • Waits 3 seconds between keys, shows live progress and has a Stop button.
  • Stops on its own if you're logged out or Steam rate-limits you.
  • Downloads a CSV report with the result for every key.
  • Drag the bar or panel header anywhere you like. It remembers where you left it.

It uses Steam's own redeem endpoint, which isn't an official API, so it can break if Steam changes it. Try one or two keys first. Keys never leave your browser except to Steam.

More on Steam pages New

  • Price card on game pages: the lowest price right now, the all-time low, and whether you own or wishlisted it (needs your Steam Value Checker link code).
  • Bundle check on bundle pages: what the games cost separately against the bundle price.
  • Cart check: warns when something in your cart is cheaper elsewhere or already in your library.
  • Key vault: keys you reveal are remembered only in your browser, so the dashboard can show what is still unredeemed.

Install

Easiest: install it from the Chrome Web Store. It updates by itself.

Add to Chrome

Brave, Opera and Vivaldi can install from the Chrome Web Store too. Edge asks you to allow extensions from other stores first.

Or install the .zip yourself

The .zip below is always the latest version. The Web Store copy updates after each review, so the .zip can be a little ahead. It is installed as an unpacked extension and takes about a minute.

Download .zip (Latest)

  1. Extract the download to a folder you'll keep. It should contain manifest.json, content.js, steam.js, background.js, bridge.js and xlsx.full.min.js.
  2. Open your extensions page: chrome://extensions, edge://extensions, brave://extensions, opera://extensions or vivaldi://extensions.
  3. Turn on Developer mode (top right, or the sidebar on Edge).
  4. Click Load unpacked and select the folder that contains manifest.json.
  5. Open your Fanatical orders and click the orange 🎮 FanaticalGrabber bar in the bottom right.

Web Store installs update by themselves. If you installed the .zip, replace the files, click Reload on the extension card, and hard-refresh Fanatical with Ctrl + Shift + R.

Questions

Does it send my keys anywhere?

No. Reading, exporting and copying all happen in your browser. Keys go to Steam only when you click Redeem. The optional "Send to Steam Value Checker" button sends game titles only, never keys. Details are in the privacy policy.

Where do I find the Steam panel?

On any store.steampowered.com page there is a pulsing 🎮 Batch Redeem bar in the bottom right. Click it to open the panel. On the Activate a Product page the panel is shown under the form automatically. Make sure you are logged into the Steam account you want the games on.

Can I move the panels?

Yes. Drag the orange bar or header on Fanatical, or the bar or header on Steam. Each remembers its own spot.

Does Redeem work for keys from other stores?

No. It only handles Steam keys and skips anything not in Steam's format. Exports include every key.

Why did Redeem say I'm not logged in?

Log into store.steampowered.com in the same browser profile, then try again. Being logged into the Steam desktop app doesn't count.

What if Steam rate-limits me?

The extension stops right away. Wait about an hour before trying again, and redeem in smaller batches.

Does it work in Firefox or Safari?

Not currently. It relies on Chromium's extension system.

Something broke. Where do I report it?

Message Jacob Lucado on X with your browser, the version shown in the panel footer, and the status message or CSV report. Feature ideas are welcome too.
